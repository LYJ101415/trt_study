 以下是NVIDIA TensorRT 工具集 Polygraphy 的命令行界面（CLI）示例文件夹。其核心作用是通过一系列具体的命令行示例，展示如何使用 Polygraphy 的 CLI 工具进行模型调试、分析和优化。
这些示例是学习 Polygraphy 命令行工具的绝佳教材，适用于希望通过脚本化、非编程方式快速验证模型、定位问题或自动化工作流的开发者。
 核心功能文件夹
check/
作用：包含用于模型检查的示例，如 01_linting_an_onnx_model。它演示了如何使用 polygraphy check 命令来验证 ONNX 模型的结构和语法是否正确。
应用场景：
模型完整性验证：在模型转换或修改后，快速检查 ONNX 模型文件是否损坏或存在不合规的结构。
问题初步排查：作为调试流程的第一步，排除因模型文件本身错误导致的问题。
convert/
作用：包含将模型从一种格式转换为另一种格式的示例。它演示了如何使用 polygraphy convert 命令，例如将 ONNX 模型转换为 TensorRT 引擎（.plan 文件）。
应用场景：
模型部署准备：将训练好的模型（如 ONNX）转换为适用于高性能推理的 TensorRT 引擎。
格式互转：在不同的模型格式之间进行转换，以便于使用不同工具进行分析。
debug/
作用：包含用于调试模型精度问题的示例。它演示了如何使用 polygraphy debug 子命令（如 accuracy）来定位导致模型输出与预期不符的网络层。
应用场景：
精度问题定位：当 TensorRT 引擎的推理结果出现精度损失时，自动二分查找并定位到具体是哪个或哪些网络层导致了问题。
算子实现验证：验证特定层（尤其是自定义插件）在 TensorRT 中的实现是否与原始框架（如 PyTorch）一致。
inspect/
作用：包含用于检查和分析模型及引擎文件的示例。它演示了如何使用 polygraphy inspect 命令来查看模型的输入/输出、网络结构、权重，或 TensorRT 引擎的详细构建信息和序列化内容。
应用场景：
模型/引擎结构分析：在不使用可视化工具的情况下，通过命令行快速了解模型或引擎的内部细节。
调试信息获取：获取引擎的构建配置、层精度、显存占用等信息，用于性能分析和优化。
plugin/
作用：包含处理自定义插件（Plugin）的示例，如 01_match_and_replace_plugin。它演示了如何匹配模型中的特定层并用自定义插件替换，或为插件提供精度验证的“黄金”实现。
应用场景：
自定义算子集成：在模型中集成 TensorRT 官方不支持的自定义算子。
插件精度调试：为自定义插件创建一个基于 NumPy 或 PyTorch 的“模拟器”，用于验证插件实现的正确性。
run/
作用：包含运行模型推理并比较结果的示例。它演示了如何使用 polygraphy run 命令，用不同的后端（如 trt, onnxrt, tf, torch）运行同一个模型，并比较它们的输出。
应用场景：
跨框架/后端精度对齐：验证模型从 PyTorch/TensorFlow 转到 ONNX，再转到 TensorRT 的过程中，输出结果是否保持一致。
快速推理测试：使用命令行快速对模型进行一次推理，检查其基本功能是否正常。
surgeon/
作用：包含对模型进行“手术”级修改的示例。它演示了如何使用 polygraphy surgeon 命令来提取子图、移除层、修改输入/输出等。
应用场景：
模型结构修改：移除模型中与推理无关的层（如 Loss 层），或提取模型的一部分用于单独测试。
模型优化预处理：在进行模型转换前，对模型结构进行一些手动的、定制化的调整。
