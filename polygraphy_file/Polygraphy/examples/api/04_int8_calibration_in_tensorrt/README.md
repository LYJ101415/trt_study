# Int8 Calibration In TensorRT


## Introduction

Int8 calibration in TensorRT involves providing a representative set of input data
to TensorRT as part of the engine building process. The
[calibration API](https://docs.nvidia.com/deeplearning/tensorrt/api/python_api/infer/Int8/Calibrator.html)
included in TensorRT requires the user to handle copying input data to the GPU and
manage the calibration cache generated by TensorRT.

While the TensorRT API provides a higher degree of control, we can greatly simplify the
process for many common use-cases. For that purpose, Polygraphy provides a calibrator, which
can be used either with Polygraphy or directly with TensorRT. In the latter
case, the Polygraphy calibrator behaves exactly like a normal TensorRT int8 calibrator.

In this example, we'll look at how you can use Polygraphy's calibrator to calibrate a network
with (fake) calibration data, and how you can manage the calibration cache with just a single
parameter.


## Running The Example

1. Install prerequisites
    * Ensure that TensorRT is installed
    * Install other dependencies with `python3 -m pip install -r requirements.txt`

2. Run the example:

    ```bash
    python3 example.py
    ```

3. The first time you run the example, it will create a calibration cache
    called `identity-calib.cache`. If you run the example again, you should see that
    it now uses the cache instead of running calibration again:

    ```bash
    python3 example.py
    ```

==============================================================
这份文档标题为 “Int8 Calibration In TensorRT”，是 NVIDIA Polygraphy 工具包中关于 INT8 量化校准 的核心示例。其目标是大幅简化 TensorRT 原生 INT8 校准流程的复杂性，同时保持与原生 API 的完全兼容性。核心概念:
INT8 量化：将模型权重和激活值从 FP32/FP16 转换为 8 位整数，显著降低内存占用和计算量，提升推理吞吐（尤其在支持 INT8 的 GPU 上）。
校准（Calibration）：由于 INT8 动态范围有限（-128~127），需通过少量真实数据（通常 100~1000 张图）统计激活值的分布，确定缩放因子（scale），以最小化量化误差。
校准缓存（Calibration Cache）：TensorRT 将校准结果（各层的 scale 值）保存为二进制文件（.cache），后续构建引擎时可直接复用，无需重新校准。
关键点：校准是一次性过程，缓存可跨引擎构建复用（只要模型结构不变）。

原生 TensorRT 校准的痛点:手动 GPU 数据拷贝：
需实现 get_batch() 方法，将 CPU 数据显式拷贝到 GPU 内存（涉及 CUDA 上下文、内存分配等）。
缓存管理复杂：需重写 read_calibration_cache() / write_calibration_cache() 方法，处理文件 I/O 和二进制格式。
样板代码冗长：即使简单场景，也需编写 50+ 行 boilerplate 代码。
Polygraphy 的解决方案：Calibrator
Calibrator 是一个工厂函数，返回符合 TensorRT 接口的校准器对象。完全兼容原生 API：Polygraphy 生成的校准器可直接传给 IBuilderConfig.set_int8_calibrator()。

运行机制详解：
步骤 1：首次运行 → 执行校准 + 生成缓存
程序使用 fake calibration data（如随机张量）运行校准。TensorRT 分析激活值分布，计算各层 scale。结果保存为 identity-calib.cache。
步骤 2：再次运行 → 跳过校准，直接加载缓存：Polygraphy 检测到 identity-calib.cache 存在。直接读取缓存中的 scale 值，跳过耗时的校准过程。引擎构建速度大幅提升（校准通常占构建时间 90%+）。生产建议：校准后应永久保存 .cache 文件，作为模型资产的一部分。
