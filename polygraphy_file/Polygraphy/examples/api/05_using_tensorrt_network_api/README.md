# Using The TensorRT Network API


## Introduction

In addition to loading existing models, TensorRT allows you to define networks by hand
using the network API.

In this example, we'll look at how you can use Polygraphy's `extend` decorator, covered in
[example 03](../03_interoperating_with_tensorrt), in conjunction with the `CreateNetwork`
loader to seamlessly integrate a network defined using TensorRT APIs with Polygraphy.


## Running The Example

1. Install prerequisites
    * Ensure that TensorRT is installed
    * Install other dependencies with `python3 -m pip install -r requirements.txt`

2. **[Optional]** Inspect the TensorRT network generated by `create_network()`.
    This will invoke `create_network()` from within the script and display the generated TensorRT network:

    ```bash
    polygraphy inspect model example.py --trt-network-func create_network --show layers attrs weights
    ```

3. Run the example:

    ```bash
    python3 example.py
    ```

这份文档标题为 “Using The TensorRT Network API”，是 NVIDIA Polygraphy 工具包中关于 “从零手写 TensorRT 网络” 的高级示例。其核心目标是展示：如何将原生 TensorRT 网络构建代码无缝集成到 Polygraphy 的工作流中，从而同时享受“手动建图的灵活性”和“Polygraphy 的工程便利性”。为什么需要手写 TensorRT 网络？
常见需求场景：
模型结构无法通过 ONNX 表达;如自定义 CUDA 插件（Plugin）、动态控制流（非标准 ONNX op）。
极致性能优化;手动融合层、调整内存布局、插入特定优化策略。
快速原型验证;无需导出 ONNX，直接在 TensorRT 中构建小型网络测试算子行为。
修复 ONNX 转换问题;当 onnx-tensorrt 解析失败时，手动重建网络。
挑战：原生 TensorRT 手动建图代码冗长（需管理 builder/network/layer），且难以与后续 Polygraphy 工具（如 TrtRunner、inspect）集成。

Polygraphy 的解决方案：CreateNetwork + @func.extend
核心组件：
组件	               作用
CreateNetwork	Polygraphy 提供的 lazy loader，用于创建空的 TensorRT 网络（返回网               (builder, network)）
@func.extend	装饰器，允许在 CreateNetwork 返回后立即注入自定义建图逻辑
关键优势：
无缝衔接：手写网络 → Polygraphy 引擎构建 → Runner 推理 → inspect 调试，全流程打通。
零样板代码：无需手动管理 IBuilder 生命周期或错误处理。
调试友好：可通过 polygraphy inspect 直接可视化手写网络。
